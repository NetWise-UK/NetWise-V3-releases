# V3 Style Gallery

A development-only design showroom for the NetWise V3 multi-style project.

**Open `index.html` in any browser** — no build step, no server, no dependencies
(fonts load from Google Fonts; everything else is inline).

- Gallery landing page with previews of all five design directions.
- Style switcher (top bar) re-renders the *same page* in any style for direct comparison.
- Page menu: homepage, content page, news listing, article, meetings, documents, contact,
  search, 404, and a per-style component sheet.
- "Mobile preview" shows the current page at 390 px; resizing the window exercises each
  design's full responsive behaviour.
- All five styles use one shared content model (Little Wychford Parish Council), including
  deliberately awkward content: an extra-long headline, an article with no image, long
  document titles and draft-minutes states.

These are **prototypes** — nothing here touches the production V3 theme. See
`../docs/design-audit-and-style-architecture.md` for the audit and the implementation
architecture each direction maps onto.
